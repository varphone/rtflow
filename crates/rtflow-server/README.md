# rtflow-server

Out-of-the-box streaming server built on the `rtflow` workspace: RTSP, RTMP,
SRT, WebRTC (WHIP/WHEP), HLS/LL-HLS, DASH, HTTP-FLV, recording, VOD, path
registration/discovery, stream keys and HTTP auth hooks.

See `deploy/rtflow.toml` and `docs/guides/server.md` at the repository root.
