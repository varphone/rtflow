# 管理控制台

控制台路径为 `/admin`（默认 HTTP `3000`），使用 `[http] admin_username` 与
`admin_password`/`RTFLOW_ADMIN_PASSWORD` 登录。

登录提交时按钮进入“登录中…”加载态并禁止重复提交。登录页为分栏品牌视图：左侧展示协议/可观测/安全能力，右侧为账号表单；移动端收为单卡并保留品牌。

## 页面

- **运行**：概览（KPI 与异常聚合）、直播流、点播。
- **配置**：路径、推流密钥、RTSP 代理、SRT 拉/推、录制任务。
- **系统**：脱敏 TOML、数据库 schema/大小、构建特性。

业务配置写入 SQLite；服务配置只读，修改 `rtflow.toml` 后 SIGHUP 或重启。

系统页支持复制/下载只读 TOML，并可复制数据库备份命令。


## 操作

- 列表工具栏展示“总数 + 关键状态”（直播中 / 已缓存 / 启用 / 有效）；支持搜索/状态筛选；行操作按实体显示编辑、断开、重启、探测、删除。
- 新建/编辑使用右侧抽屉；密钥 secret 只显示一次；对话框限制 Tab 焦点、默认聚焦取消并支持 Esc。
- 所有写操作经过会话 Cookie + CSRF；也支持 Basic/Bearer API。
- `#/config/paths` 等 hash 可直接刷新/分享；浏览器标题随页面更新。
- 侧栏显示在线流/代理/SRT 数量；概览提供快捷操作与无流时的推流示例。
- 概览趋势图可在“接收帧速率 / 订阅连接”之间切换，展示近 2 分钟与峰值；
- 概览与直播页显示最近一次数据刷新时间；概览默认每 8 秒原地刷新 KPI、活跃流、异常与最近变更，可随时关闭；异常数 >0 时
  KPI 卡片以警示色高亮；顶部展示
  近 2 分钟接收帧速率曲线与峰值。
- 移动端使用双列 KPI、收缩顶栏与表格首列/操作列；直播表额外保留状态列，
  行操作收敛为 HLS/断开，详情通过点击流名打开。
- 顶栏用户菜单集中提供外观、表格密度、时间显示与退出登录；选择保存在 localStorage。
- 顶栏可切换表格“舒适/紧凑”密度；命令面板可切换绝对/相对时间；
`Ctrl+K`（macOS `Cmd+K`）打开命令面板，可跳转页面、刷新、切换主题、复制当前链接。
- 表单抽屉检测未保存修改，关闭前确认。
- 直播流表格支持流名/状态/订阅/帧数列排序；本地即时搜索/状态筛选；点击流名称打开详情抽屉（打开期间每 3 秒刷新指标），查看轨道、RTP 指标、
  播放地址并复制/预览/断开。
- 直播流支持多选与批量断开，选择状态在筛选时保留；页面默认每 5 秒原地刷新指标，
  可关闭，且保留搜索/筛选/选择。
- 路径与推流密钥支持本地即时搜索、列排序，密钥可一键复制 Key ID。
- 点击路径名打开详情：策略、协议、时间、HLS/RTMP 地址、复制与关联的直播/点播/录制跳转。
- RTSP 代理与 SRT 页支持本地搜索/状态筛选；SRT 推拉流切换不再重新加载页面；
  点击 SRT 名称打开详情，查看远端/连接/延迟/加密/流量与错误，并编辑/启停/删除；
  可复制远端地址或跳转到对应 Mount。
- 点击代理路径打开详情：运行状态、模式、订阅/轨道/重试/流量、上游列表，并可直接编辑、
  重启、探测或删除。录制行新增“点播”入口，按路径跳转点播筛选。
- 录制页支持搜索、状态筛选与按路径/分段/大小排序，自动刷新只更新现有单元格；
  点击路径打开录制详情，查看目录/开始时间/分段/写入量并可停止或跳转点播；
  详情打开期间每 2 秒刷新写入量与分段。
- 点播以封面卡片展示时长/录制时间，搜索本地即时过滤，播放/复制/刷新缓存保持原位。
- 点播页每 10 秒原地刷新生成缓存状态，播放后徽标自动变为“已缓存”。
- 点播卡片与详情展示生成缓存状态/占用大小；点击标题打开详情，查看时长/
  录制时间/格式/资源 ID 与绝对 HLS 地址。
- 审计行可打开事件详情（时间/动作/结果/用户/协议/路径/Key ID/来源/原始 JSON），
  并可直接跳到关联路径/直播/代理/录制/SRT 的筛选视图。
- “系统 → 审计日志”读取 append-only JSONL 审计记录，支持搜索与“变更/认证”分类，
  可按当前筛选导出 CSV（含 BOM，Excel 可直接打开）；非第一页收到新事件时显示
  “N 条新事件”提示，点击应用并回到最新页；
  25 条/页分页，并在页面可见时每 5 秒自动刷新（可关闭）。

## 开发

前端资源位于 `crates/rtflow-admin/src/assets/`，由 Rust `include_bytes!` 嵌入：

```text
app.js        启动、会话、路由、shell
js/api.js     fetch/CSRF/错误
js/pages/*    页面
js/forms/*    抽屉表单
```

无 npm/Vite 构建；修改后重新编译 `rtflow-server`。新增静态文件需加入
`crates/rtflow-admin/src/api/assets.rs` 的 `ASSETS` 清单。
